# Requisicoes

Aplicativo mobile desenvolvido em React Native com foco em requisições HTTP e consumo de API externa.

## Sobre o projeto

O **Requisicoes** foi desenvolvido para praticar o consumo de dados externos em uma aplicação React Native.

O projeto trabalha com requisições HTTP, carregamento de dados, exibição de listas e apresentação de detalhes em tela/modal, simulando uma aplicação que busca informações em uma API e apresenta os resultados ao usuário.


## Funcionalidades

- Consumo de API externa
- Requisições HTTP
- Controle de carregamento dos dados
- Listagem de informações
- Exibição de detalhes
- Uso de estados
- Uso de efeito ao carregar a aplicação
- Organização de componentes

## Tecnologias utilizadas

- React Native
- JavaScript
- Expo
- Axios
- API externa
- Node.js / npm

## Estrutura do projeto

O projeto possui uma estrutura com os arquivos principais da aplicação, incluindo:

- `src` - código-fonte da aplicação
- `App.js` - arquivo principal do app
- `package.json` - dependências e scripts do projeto

## Como executar o projeto

1. Clone este repositório:

```bash
git clone https://github.com/JohnElthon/Requisicoes.git
```

2. Acesse a pasta do projeto:

```bash
cd Requisicoes/requisicoesRN
```

3. Instale as dependências:

```bash
npm install
```

4. Execute o projeto:

```bash
npm start
```

5. Abra no emulador Android/iOS ou no aplicativo Expo Go.

## Observação

Projeto desenvolvido com fins acadêmicos para praticar requisições, consumo de API e renderização de dados em React Native.
